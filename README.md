# Проект первичного анализа данных (EDA)

## Настройка окружения
Окружение настроено с помощью **venv**, так как это встроенный легкий инструмент Python, не требующий установки сторонних менеджеров пакетов.

## Структура проекта
- `data/` — исходные наборы данных
- `notebooks/` — Jupyter Notebooks с первичным анализом
- `README.md` — описание проекта
