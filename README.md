# Практическая работа № 1. Настройка окружения и первый Notebook

## 1. Цель работы

Цель практической работы — настроить рабочее окружение для машинного обучения, подготовить Jupyter Notebook и провести первичный анализ табличного датасета.

В ходе работы необходимо изучить структуру данных, определить типы столбцов, проверить наличие пропущенных значений, рассчитать основные статистические показатели и построить графики для визуального анализа данных.

## 2. Используемые технологии

В работе используются следующие инструменты и библиотеки:

- **Python** — язык программирования для анализа данных и машинного обучения.
- **Jupyter Notebook** — интерактивная среда для выполнения кода, отображения результатов и написания текстовых пояснений.
- **Pandas** — библиотека для загрузки, обработки и анализа табличных данных.
- **NumPy** — библиотека для работы с числовыми данными и массивами.
- **Matplotlib** — библиотека для построения графиков.
- **Seaborn** — библиотека для визуализации данных на основе Matplotlib.
- **Scikit-learn** — библиотека для машинного обучения.
- **Git и GitHub** — инструменты для контроля версий и хранения проекта в удалённом репозитории.

### Выбор виртуального окружения

Для проекта используется виртуальное окружение Python `venv`. Оно позволяет изолировать зависимости проекта от системного Python и других проектов. Благодаря этому библиотеки можно устанавливать отдельно для каждой работы.

## 4. Описание датасета

Для выполнения работы используется датасет `tips`, содержащий информацию о счетах в ресторане, чаевых и характеристиках обслуживания.

Датасет подходит для первичного анализа, поскольку содержит как числовые, так и категориальные признаки.

В нём представлены следующие столбцы:

| Столбец | Описание | Тип данных |
|---|---|---|
| `total_bill` | Общая сумма счёта | Числовой |
| `tip` | Размер чаевых | Числовой |
| `sex` | Пол посетителя | Категориальный |
| `smoker` | Наличие признака курения у посетителя | Категориальный |
| `day` | День недели | Категориальный |
| `time` | Время приёма пищи: обед или ужин | Категориальный |
| `size` | Количество человек за столом | Числовой |

Датасет позволяет исследовать распределение счетов и чаевых, а также сравнивать показатели между разными категориями посетителей.

## 5. Этапы выполнения работы

### 5.1. Настройка окружения

Для работы подготовлено окружение Python и установлены библиотеки, необходимые для анализа данных и построения графиков.

Используемые библиотеки:

```bash
pip install pandas numpy matplotlib seaborn jupyter scikit-learn
```

### 5.2. Загрузка данных

Датасет загружается в Pandas DataFrame для дальнейшего анализа.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

df = pd.read_csv("../data/tips.csv")
```

Использование относительного пути позволяет запускать проект из репозитория без привязки к конкретному расположению файлов на компьютере.

### 5.3. Первичный осмотр данных

Для знакомства с датасетом используются следующие методы:

- `df.head()` — отображает первые пять строк таблицы.
- `df.info()` — показывает количество записей, названия столбцов, типы данных и количество непустых значений.
- `df.describe()` — рассчитывает основные статистические показатели числовых столбцов.
- `df.shape` — возвращает количество строк и столбцов.
- `df.dtypes` — показывает тип данных каждого столбца.
- `df.isnull().sum()` — определяет количество пропущенных значений в каждом столбце.

Эти операции позволяют оценить структуру датасета, проверить качество данных и определить, какие признаки можно использовать для дальнейшего анализа.

### 5.4. Визуализация данных

Для визуального исследования датасета строятся как минимум два графика.

**График 1. Распределение общей суммы счёта**

Гистограмма позволяет оценить, какие значения общей суммы счёта встречаются чаще всего, и понять характер распределения признака `total_bill`.

**График 2. Сравнение общей суммы счёта по дням недели**

Столбчатая диаграмма позволяет сравнить среднюю сумму счёта в разные дни недели и определить возможные различия между категориями.

Визуализация помогает обнаруживать закономерности, которые не всегда очевидны при изучении одной только таблицы статистических показателей.

## 6. Основные наблюдения

После выполнения анализа в Jupyter Notebook формулируются три наблюдения на основе полученных результатов.

1. **Распределение счетов:** анализ гистограммы позволяет определить диапазон сумм, в котором сосредоточена основная часть наблюдений, и выявить возможные необычно большие счета.
2. **Различия между днями недели:** сравнение средней суммы счёта по дням позволяет определить, отличаются ли расходы посетителей в разные дни.
3. **Связь суммы счёта и чаевых:** сравнение признаков `total_bill` и `tip` позволяет проверить, наблюдается ли тенденция к увеличению чаевых при увеличении общей суммы счёта.

Окончательные выводы формулируются на основании фактических результатов анализа и построенных графиков.

## 8. Запуск проекта

Для запуска проекта необходимо выполнить следующие действия.

**1. Клонировать репозиторий:**

```bash
git clone <URL_репозитория>
```

**2. Перейти в каталог проекта:**

```bash
cd PR-1
```

**3. Создать виртуальное окружение:**

```bash
python3 -m venv venv
```

**4. Активировать виртуальное окружение в Ubuntu:**

```bash
source venv/bin/activate
```

```bash
pip install pandas numpy matplotlib seaborn jupyter scikit-learn
```

**6. Запустить Jupyter Notebook:**

```bash
jupyter notebook
```

После запуска необходимо открыть файл `notebooks/eda.ipynb` и выполнить все ячейки последовательно.
